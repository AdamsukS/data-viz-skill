## Purpose

This composition asks whether a generative model has recovered a complete distribution of functions. The top row compares a worst-case generated function with its parametric reconstruction at each training-set size. The bottom row shows recovered function-parameter distributions and reconstruction error. It can be adapted to temporal signals, spectra, trajectories, sensor responses and other one-dimensional functional data.

The composition is inspired by Figure 2 of Wang et al., FunDiff, Nature Communications: [`10.1038/s41467-026-72292-0`](https://doi.org/10.1038/s41467-026-72292-0). The official implementation is [`sifanexisted/fundiff`](https://github.com/sifanexisted/fundiff).

## Data provenance

**deterministic_synthetic_inspired_by_published_layout** — The bundled CSVs are generated by `simulate_data.py` with fixed seed `20260427` solely to demonstrate the reusable composition. They are not original paper data, author-checkpoint outputs or digitized values from the published figure.

The simulator uses training sizes `16, 32, 64, 128, 256` and creates 1,024 parameter records per size. Proxy parameter laws move from biased beta distributions toward the target uniforms as training size grows, while median MSE falls. The top row constructs a consistent residual example from the maximum-MSE record in each group.

## Raw data required for real reuse

- Training-function count, random seed and model/configuration ID for every model.
- A unique `sample_id`, coordinates, generated values and fitted or reconstructed values for every function.
- Fitted amplitude `A`, damping `gamma`, angular frequency `omega`, vertical shift `b` and MSE for every function.
- Target parameter distributions or defensible bounds. If the real task has no analytic parameters, replace them with defined peaks, derivatives, integrals, spectral energy or other function features.

For real model results, select the maximum-MSE curve in every group for the top row. The bottom-row parameters and MSE must come from the same generated sample set. Do not mix the demonstration CSVs with real outputs.

## Files and columns

### `data/figure23_parameters.csv`

5,120 rows; one fitted summary per generated function.

| Column | Type | Unit | Meaning |
|---|---|---|---|
| `train_n` | integer | functions | Number of training functions |
| `sample_id` | integer | ID | Generated-sample ID within group |
| `amplitude` | number | function-value units | Fitted amplitude A |
| `damping` | number | inverse coordinate | Damping coefficient gamma |
| `frequency` | number | radian per coordinate | Angular frequency omega |
| `shift` | number | function-value units | Vertical shift b |
| `mse` | positive number | squared function-value units | MSE between generated and reconstructed curves |

### `data/figure23_curves.csv`

640 rows; 128 coordinate points for each training-set size.

| Column | Type | Unit | Meaning |
|---|---|---|---|
| `train_n` | integer | functions | Number of training functions |
| `time` | number | normalized coordinate [0,1] | Continuous coordinate or normalized time |
| `generated` | number | function-value units | Generated-function value |
| `reconstructed` | number | function-value units | Parametric reconstruction value |

## Run

From the repository root:

```bash
python -m figures.figure23.simulate_data
python -m figures.figure23.plot --format png svg pdf
```

With replacement CSVs:

```bash
python render.py --figure 23 --data-dir ./my_figure23_data --out ./my_output --format png svg pdf --annotations none
```

Update `style.json` when changing training sizes, parameter bounds, labels or colors. Do not run `simulate_data.py` on a real-output data directory because it overwrites the two bundled CSVs.
